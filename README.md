# Akıllı Sulama Zamanlama Sistemi

Bu proje tarımsal verilerle sulama ihtiyacını tahmin eden bir makine öğrenmesi modeline sahiptir.

**Durum Bilgisi:**
Şu an için projenin **Frontend (Önyüz)** kısmı henüz hazır değildir / geliştirilmemiştir. Ancak **Backend (Arkayüz)** kısmı, makine öğrenmesi modelleri ve ileri düzey (advanced) test süreçleriyle birlikte tamamen **bitmiş ve tamamlanmıştır**. Modeller başarıyla eğitilmiş ve çeşitli sızıntı/overfitting testlerinden (ROC, Holdout, vs.) geçmiş durumdadır.
